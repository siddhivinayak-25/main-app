# hiresprint Product Demo Assets

This folder contains everything you need to create a 60–75 second product demo video using a video editor or Veo/Whisper.

| `veo-prompts.md` | Veo prompts for each scene |
| `storyboard.md` | Combined scene / image / transcript / prompt reference |

## How to use

1. **With Veo:** Feed each screenshot + its matching Veo prompt to generate a short animated clip. Join the clips in order and overlay the transcript lines as voiceover.

2. **With Whisper:** Use the transcript.md as the script. Record or generate voiceover, then sync it with the screenshots in any video editor (CapCut, Premiere, Canva, etc.).

3. **Quick Ken-Burns version:** Import the screenshots into any editor, apply slow zoom/pan, and read the transcript lines.

## Demo narrative arc

Problem → Platform value → Test creation → Invitation & email → Candidate experience → Agentic scoring → Recruiting decision.

## Suggested final prompt for Veo (one-shot)

> A 60-second professional SaaS product demo video. Start with a dark purple landing page, move through a recruiter login, a dashboard, a test creation form, an invitations table, a candidate welcome page, a browser IDE with an AI panel, then back to a recruiter dashboard and a session replay screen. Slow smooth camera moves: zooms, pans, and tracking shots. Crisp UI text, modern gradient colors, no camera shake, premium tech aesthetic. 4K.
